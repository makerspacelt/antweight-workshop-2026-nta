## Antweight robot workshop for NTA 2026 camp

- `software/robot` - Antweight robot control code with support for bluepad32 library (many gamepads including xbox/playstation etc.), custom ESP32-C3 based remote, web app
- `software/remote` - Code for a custom ESP32-C3 based remote to control the robot.
- `software/web-app-control` - Web app for robot control using phone's bluetooth. Works with Chromium on Android.
